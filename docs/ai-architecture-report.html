全体アーキテクチャ & 通信トポロジ

1. クライアント層 (SPA)

GitHub Pages (静的ホスティング) 上の public/index.html。

sendChat() → chatAsk() により https://api.dm-classic08.org/api/chat へ SSE 通信。URLパラメータ ?chatApi=http://localhost:8788 による動的ローカル切替に対応。

2. 境界＆トンネリング層

Cloudflare Tunnel (cloudflared daemon)。

EC2 側のポート 80/443 をパブリック開放せず、Cloudflare エッジからアウトバウンド暗号化トンネルで localhost:8788 をセキュアに終端。

3. バックエンド & LLM層

Hono + Node.js (dm-chat.service)。

メモリ上に展開した 1,848 枚のカードコーパスとデッキレシピを高速走査。Groq API (qwen/qwen3.8-27b) で推論し、未ヒット時は Tavily Web検索へ自動フォールバック。

処理パイプライン & 2段構えSentinel検索

質問受付から回答完了までの全ステップ。ローカルコーパス検索とWeb検索を知的につなぐ「2段構えSentinel」がハルシネーションを防止します。

Step 01: 検証
Request Validation
  • IPレート制限 (20req/min)
  • 文字数チェック (≤ 500字)
  • 履歴整合性 (≤ 10ターン)
  • 構造化1行JSONアクセスログ
Step 02: 探索
Hybrid Retrieval
  • 俗称・エイリアス展開
  • 属性・タグ・役割・パワー照合
  • デッキ意図判定 & 40枚マッピング
  • 最大8枚をコンテキスト化
Step 03: 判定
[[WEB]] Sentinel Detect
  • 第1段LLM推論ストリーム開始
  • 先頭数トークンをメモリバッファ
  • [[WEB]] 検知で即破棄しWeb検索へ
  • 通常回答ならそのままクライアントへ
Step 04: 返却
SSE Done Payload
  • ストリーミング完了通知
  • 根拠カード一覧 (cards)
  • 参考デッキ40枚 (deck)
  • 参照Webソース (sources)

ハイブリッド リトリーバー（俗称・属性・テキスト探索）

Layer 1 俗称辞書

ALIAS_MAP エクスパンダー

ユーザーのくだけた俗称を正式名称や構成要素に展開。

'ボルコン': ボルメテウス・ホワイト・ドラゴン
'エタソ': 英知と追撃の宝剣
'PG': 不滅の精霊パーフェクト・ギャラクシー
'天門': ヘブンズ・ゲート, バルホルス
Layer 2 役割・効果タグ

ROLE_PATTERNS 照合

テキスト正規表現で能力・キーワードをリアルタイム評価。

ドロー: /カードを.*枚引|ドロー/
マナ加速: /マナゾーンに置く/
ブロッカー: .includes('ブロッカー')
シノビ: .includes('ニンジャ・ストライク')
Layer 3 数値・条件

Cost / Power Filter

コスト帯やパワー条件に合致するカードをスコアリング抽出。

軽量: cost ≤ 3
大型: cost ≥ 7
パワー5000+: ディアノーク, シーブスキーン等
合致スコア順に上位最大8枚を選出

プロンプト設計 & レギュレーション制約

🚫 殿堂レギュレーション警告の自動バッジ化

禁止・制限カードが不適切に提案されることを防ぐため、プロンプトへ警告を事前注入。

[クラシック08禁止🚫:使用不可]: 無双竜機ボルバルザーク
[クラシック08制限🏅:1枚まで]: 超竜バジュラ、母なる紋章、サイバー・ブレイン等（19種）
[クラシック08枠制限⚠️:12種合計1枚]: 母なる大地、アクアン、サファイア等（12種）

📐 ハルシネーション抑止の制約ルール

  • 時代限定: 2008年DM-30戦国編第1弾まで。現代カードは「クラシック08専用」と回答。
  • 数値厳守: パワーやコストなどの数値はコンテキスト資料に記載された値のみ引用。
  • 簡潔強制: 前置きや謝罪を排除し、最大8行・1行80文字以内を徹底。
  • デッキ解説: 提示デッキがある場合、40枚リストを復唱せず軸カードと展開手順のみ説明。

ACTIVE HEALTH CHECK

モデル存在確認付き isUp()

Groq の /models 一覧を取得し、指定モデルが存在するかまで検証。モデル消失時に即座に /api/health が up: false を返し、サイレント障害を未然に防止。

const res = await f(`${DEFAULT_BASE}/models`);
const data = await res.json();
const modelExists = data?.data?.some(m => m.id === model);
return { up: modelExists, model };
